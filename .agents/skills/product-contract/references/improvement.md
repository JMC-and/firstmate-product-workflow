# Deliberate continuous improvement

Every use may append a specification correction without overwriting earlier source events, approved revisions or result attempts.
A confirmed specification defect is classified as omitted source, ambiguous question, wrong assumption, missing edge case or inadequate evidence.
The gap record contains a sanitized fixture description and a named behavioral regression.
It is private task evidence, not automatic permission to change shared tooling.

Before proposing a skill correction, reproduce the confirmed gap as a failing executable/public-interface regression using only sanitized synthetic material.
Keep the original private transcript intact and separate.
Review the smallest correction through the existing authorized contribution path and rerun the adversarial suite.
Increment the deliberate SOP version reported by `--version` for a reviewed release; the wire-schema version is separate and changes only with its format contract.
Gap records retain the SOP release that handled them.
No background updater, model confidence, or single successful use can rewrite this SOP.
Reject unknown schemas rather than silently migrating old approvals.
If a migration is needed, preserve original ledgers and require a deliberately reviewed migration and renewed approvals for changed meaning.
