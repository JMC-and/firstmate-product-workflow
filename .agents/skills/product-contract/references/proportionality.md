# Proportionality

Compact and full are presentations of the same schema and predicates.
For a narrow known fix, use one source question/answer pair, one atomic outcome, one measurable behavioral regression, one equivalent real-interface journey, explicit boundaries, one work unit and concise completion lines.
Do not ask redundant questions when a valid approved parent contract already covers the exact ask.
Generate only the assignment in that case.

Use full presentation for multiple outcomes or actors, persistence, external dependencies, consequential permissions or side effects, uncertainty, or a supplied detailed questionnaire.
File count does not determine proportionality.
A missing real dependency or unavailable credential is not a reason to relabel a task compact or exclude a requirement.
Inapplicable categories carry concrete reasons, not boilerplate defaults.
Neither profile can skip source preservation, independent semantic audit, exact approval, complete mapping or required evidence.
